# CapyCalzados
Sistema de Gestión de Ventas de Calzados

# Base de datos
Toda la base de datos (creación, tablas, procedimientos almacenados y lote completo de datos de prueba) se encuentra unificada en un único archivo: **`DBSistema.sql`**.

Tipos de perfiles:
- **Gerente** (`IdRol = 1`): Analítico (Inicio, Gráficos y Reportes)
- **Vendedor** (`IdRol = 2`): Operativo de ventas (Ventas, Clientes y visualización de Productos)
- **Manager** (`IdRol = 3`): Operativo total (Compras, Ventas, Productos, Proveedores, Clientes, Usuarios, Reportes y Gráficos)
